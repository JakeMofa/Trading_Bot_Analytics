# PLAN

This folder contains all project planning, roadmap, architecture, and planning-history documents for the BTC Intelligence / TradebotAnalytics project.

## Source of truth

**Start here:** [INTELLIGENCE_REBUILD_PLAN.md](INTELLIGENCE_REBUILD_PLAN.md)

That file is the active implementation roadmap and should be updated as work is completed.

Status convention:

- `[x]` completed
- `[~]` in progress
- `[ ]` not started

## Plan artifacts

The JSON files in this folder are planning-table artifacts/reference material. They are not the active roadmap.

## Rule going forward

Do not create new plan/roadmap documents directly under `docs/`. Put planning material in `docs/PLAN/`, and update `INTELLIGENCE_REBUILD_PLAN.md` rather than creating competing roadmaps unless there is a clear reason to preserve a separate historical reference.
